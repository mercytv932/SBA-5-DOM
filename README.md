# Blog Post Manager

A simple and responsive blog management application built with HTML, CSS, and JavaScript. Users can create, edit, save, and delete blog posts directly from the browser.

## Features

- Create blog posts with a title and content
- Automatically display the post date and time
- Edit and save existing posts
- Delete posts
- Clear form inputs
- Display the total number of posts
- Store posts in Local Storage so they remain after refreshing the page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project was created to practice JavaScript event handling, DOM manipulation, arrays, objects, and browser Local Storage.
